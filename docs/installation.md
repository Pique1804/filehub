# Установка FileHub

[English installation guide](installation.en.md)

Текущий установщик — **1.40.22**. В Linux-пакете уже есть сервер,
веб-интерфейс и подписанное Android-приложение. Чистая установка этого
пакета проверена на Debian 12 x86‑64. Для Android нужен Android 8 или новее.

[Скачать установщик Linux x86-64](https://github.com/Pique1804/filehub/releases/download/v1.40.22/filehub-1.40.22-linux-amd64-installer.tar.gz) · [Файл SHA-256](https://github.com/Pique1804/filehub/releases/download/v1.40.22/filehub-1.40.22-linux-amd64-installer.tar.gz.sha256) · [Android APK](https://github.com/Pique1804/filehub/releases/download/v1.40.22/filehub-1.40.22.apk) · [Страница выпуска](https://github.com/Pique1804/filehub/releases/tag/v1.40.22)

## Установка одной командой

Пока репозиторий приватный, установите GitHub CLI и войдите через
`gh auth login` под аккаунтом с доступом к FileHub. Запустите:

```sh
gh release download -R Pique1804/filehub -p install.sh -O - | bash
```

Когда репозиторий доступен без входа в GitHub, используйте ту же постоянную
ссылку на скрипт через `curl`:

```sh
curl -fsSL https://github.com/Pique1804/filehub/releases/latest/download/install.sh | bash
```

Скрипт скачивает текущий Linux-архив, сверяет SHA-256 и запускает установщик в
режиме обычных папок. Для записи системных файлов он использует `sudo`, если
команда запущена от обычного пользователя. Ссылка первого входа появится в терминале.

## Ручная установка в обычную папку на Linux

Скачайте архив и файл SHA-256 в одну папку на сервере Debian или Ubuntu
с systemd. Откройте терминал в этой папке и выполните команду.

```sh
sha256sum -c filehub-1.40.22-linux-amd64-installer.tar.gz.sha256 &&
tar -xzf filehub-1.40.22-linux-amd64-installer.tar.gz &&
cd filehub &&
sudo bash ./install.sh --folders-only
```

Если терминал уже открыт от имени `root`, запускайте установщик через
`bash ./install.sh --folders-only`.

Для первого запуска используйте сеть, где ваш браузер может открыть адрес
сервера. Для доступа из другой сети подключитесь через свой VPN.

Для физических дисков на Proxmox начните с [инструкции для узла](#отдельный-диск-или-подключённая-папка).
Для Docker используйте [руководство Compose](compose.md).
Для работающего FileHub есть [инструкция обновления](upgrading.md).

## Первоначальная настройка

В конце установки терминал показывает приватную ссылку на мастер с кодом.
Откройте её на устройстве, которое видит сервер по сети.

1. Создайте аккаунт администратора. Этот же логин подойдёт для веба и Android.
2. Выберите **На этом сервере** для обычной папки. Для подключённых
   накопителей нажмите **Отдельный диск** и отметьте нужные диски. Стрелка
   рядом с диском раскрывает дерево папок. Галочку можно снять.
3. Выберите существующую или пустую папку для фотоленты. Чтобы настроить
   фотоленту позже, нажмите **Пропустить фото**.
4. Проверьте выбор и нажмите **Запустить FileHub**. Страница
   **Телефон и хранилища** покажет адрес сервера и ссылку на APK.

После запуска дополнительные диски и папки для фото можно добавить через
**Телефон и хранилища → Хранилища**.

## Продолжение настройки и доступ к диску

После создания аккаунта мастер сохраняет выбранные папки и текущий шаг.
Чтобы продолжить в другом браузере, войдите под тем же аккаунтом.
Раздел «Файлы» показывает выбранное хранилище целиком или заданную подпапку.
Раздел «Фото» показывает снимки из папок фотоленты. Для загрузки новых файлов
выберите доступную для записи папку. [Как устроены хранилища](storage.md).

## Отдельный диск или подключённая папка

На обычном Linux подключите накопитель к серверу и при первой установке
запустите `sudo bash ./install.sh` для включения управления физическими дисками.

Для **Proxmox LXC** подключите накопитель к компьютеру с Proxmox. В панели
Proxmox выберите сам узел в дереве слева и откройте **Shell**. Скачайте на
узел архив и SHA-256, проверьте и распакуйте архив. В папке установщика
выполните команду, заменив `CTID` номером запущенного контейнера.

```sh
bash ./install.sh --proxmox CTID --restart
```

Установщик подготовит подключение дисков и перезапустит контейнер. Откройте
мастер, выберите **Отдельный диск** и подключите нужные накопители. FileHub
монтирует разделы с готовой файловой системой. После подключения отметьте
нужные диски и выберите папки.

Если диск уже смонтирован на узле, перед первой установкой FileHub добавьте
нужную папку в контейнер как точку монтирования. В мастере выберите её среди
доступных хранилищ. В Docker укажите папку диска в настройках Compose.
[Справка администратора по дискам](../server/host-storage/README.md).

## Скачать FileHub для Android со своего сервера

После входа в веб-интерфейс нажмите **Скачать приложение** в боковом меню.
В мобильном браузере кнопка называется **Android**. Откройте скачанный APK,
укажите адрес того же сервера и войдите со своим логином.

Этот же APK можно скачать из релиза по ссылке в начале страницы. Обновления
приложение проверяет на вашем FileHub в **Настройки → Приложение → Проверить обновление**.

[Как разместить следующее Android-обновление](upgrading.md#обновить-только-приложение-android).

## Код первой настройки

Терминал печатает приватную ссылку вида `/setup#code=...` и путь к файлу
`setup-code.json`. Если ссылка потерялась, администратор сервера может
прочитать этот файл и ввести код в мастере. Пароль аккаунта создаётся
отдельно. После создания администратора для продолжения нужны его логин и пароль.

## Резервное копирование

Администратор настраивает копирование в «Настройки → Резервное копирование».
Выберите папки на подключённых хранилищах, папку назначения, дни и время
по часовому поясу сервера. Можно проверить настройку кнопкой
«Создать копию сейчас». Для копирования требуются Python 3 и rsync.

Завершённые снимки лежат в подпапке `.filehub-server-backups` выбранного
назначения. Внутри снимка `manifest.json` описывает размещение выбранных
папок, базы `index.db` и файлов версий из этих папок. Выключение расписания
сохраняет готовые снимки и позволяет текущему запуску завершиться.

В новых установках расписание по умолчанию выключено. В существующих
установках первая запись этих настроек заменяет прежнее внутреннее
расписание копирования SQLite. Задания, настроенные вне FileHub, оператор
управляет отдельно.

## Предпросмотр документов и libvips

На Debian и Ubuntu можно добавить libvips для обработки изображений,
LibreOffice для предпросмотра Word, Excel и PowerPoint, а также русские
словарные данные Tesseract для распознавания надписей.

```sh
sudo apt-get update
sudo apt-get install --no-install-recommends libvips-tools libreoffice-writer \
  libreoffice-calc libreoffice-impress poppler-utils tesseract-ocr-rus
```

Перезапустите сервер и его веб-прокси. Для установки со стандартным именем:

```sh
sudo systemctl restart filehub-onboarding.service filehub-onboarding-front.service
```

Проверьте состояние инструментов в настройках сервера.
