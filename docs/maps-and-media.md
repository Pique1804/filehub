# Карта, фотолента и загрузки 1.40.2

В Android откройте «Фото → Места», в вебе — «Места» в боковом меню.
Снимки группируются по масштабу карты. Нажмите на группу, чтобы приблизить
место и увидеть её снимки. «Фото в этой области» выбирает снимки в текущем
окне карты. Фильтр дат включает весь последний выбранный день в часовом поясе
устройства. Координаты берутся из EXIF уже добавленных фотографий; Filehub
не запрашивает текущую геолокацию телефона.

На карте можно открыть полный просмотрщик фото и видео. В Android сохраняются
существующие увеличение, свайпы, избранное и сведения о снимке. В вебе PhotoSwipe
добавляет увеличение колёсиком/жестом, переключение стрелками и закрытие Escape.
Отображаются только снимки в настроенных фото-папках. При отсутствии GPS карта
объясняет, почему она пуста. Сбой API отображается как ошибка с повтором.

В веб-фотоленте сервер возвращает по 240 записей, а браузер отрисовывает видимые
строки с небольшим запасом. Прокрутка загружает следующую порцию. Ошибка следующей
порции сохраняет уже открытые снимки и предлагает повторить запрос. API сохраняет
старые `limit`/`offset` для существующих Android-клиентов; новый `after` использует
стабильный порядок по дате, источнику и пути, без изменения схемы базы.

Поиск «Текст на фото или скриншоте» ищет распознанные слова через существующий OCR.
Он учитывает текущую папку и выбранный альбом. Первые 500 результатов возвращаются
из общего числа совпадений. Новые снимки появляются в OCR после фоновой обработки;
CLIP и семантическая модель для этого не нужны.

В очереди загрузок выполняются до трёх передач одновременно. Доступны пауза,
продолжение, повтор ошибки и удаление из очереди. Источник и папка фиксируются
при добавлении файла: переход в другую папку не меняет место уже начатой передачи.
После перезагрузки страницы нужно повторно выбрать тот же локальный файл в той же
папке: TUS продолжит сохранённую частичную передачу, если она ещё есть на сервере.
Браузер не получает постоянный доступ к локальным файлам. Выход из аккаунта
останавливает очередь; другой аккаунт не использует её сохранённые адреса.

Кнопка «Загрузить папку» сохраняет пути файлов вместе с именем выбранной папки.
Окно выбора файлов браузера передаёт только файлы. Чтобы перенести и пустые
папки, перетащи дерево в окно FileHub в браузере с поддержкой перетаскивания
папок. В очереди можно повторить только неудачные загрузки.

В диалогах копирования и переноса можно выбрать целевое хранилище и папку.
После копирования, переноса или удаления нескольких элементов диалог показывает
итог для каждого элемента и позволяет повторить только операции с ошибками.

Незавершённая передача хранится семь дней с последней записи. После истечения
срока сервер освобождает место в течение часа. Если сохранившийся адрес уже
недоступен, веб сообщает об этом и начинает передачу выбранного файла заново.
Администратор может посмотреть объём и время последней записи в меню
«Незавершённые загрузки» и удалить остановленную частичную передачу. Активную
передачу нужно сначала приостановить. Готовые файлы и квитанции сохраняются.

## Источник подложки карты

Сервер и приложение получают общий стиль из защищённого `/api/maps/config`.
По умолчанию используются растровые тайлы OpenStreetMap и шрифты MapLibre.
Для них нужен доступ устройства к интернету. Подложка запрашивается непосредственно
клиентом, без передачи Filehub cookies. Провайдер видит запрошенную область карты.
Нет поиска адресов, пакетной загрузки тайлов и скачивания карты для офлайн-доступа.

Для публичных файлов веб-интерфейса и worker карты Filehub задаёт
`Referrer-Policy: strict-origin-when-cross-origin`: внешний сервис получает только
origin сервера, без пути, поискового запроса и параметров. Это требуется для
веб-доступа к стандартным тайлам OpenStreetMap. Не заменяйте эту политику на
`no-referrer` в обратном прокси: OpenStreetMap может показать плитки «Access blocked».
У API, ссылок общего доступа и оригиналов сохраняется `no-referrer`.
Правила провайдера: https://operations.osmfoundation.org/policies/tiles/.

Оператор может задать в окружении серверной службы:

```ini
FILEHUB_MAP_TILES=https://tiles.example.org/{z}/{x}/{y}.png
FILEHUB_MAP_ATTRIBUTION=© Your tile provider
```

Укажите настоящий адрес провайдера со всеми тремя подстановками и его атрибуцию.
Используйте HTTPS для Filehub, открытого по HTTPS. Не включайте в URL личные
секреты: стиль доступен вошедшим пользователям приложения. Лицензия движка карты
не снимает ограничения выбранного сервиса тайлов. Для большого числа установок
используйте подходящий провайдер или собственные тайлы.

## Постеры фильмов и сериалов

Локальные `poster.jpg`, `poster.png`, `poster.webp`, `folder.jpg` и `cover.jpg`
в папке фильма или сериала имеют приоритет. WEB-панель распознаёт
внешние совпадения TMDB после включения интеграции на сервере.

Получите **API Key** или **API Read Access Token** в [настройках TMDB](https://developer.themoviedb.org/docs/authentication-application).
Войдите в веб-интерфейс как администратор, откройте «Настройки → Сервер → Постеры
и описания TMDB» и сохраните ключ. FileHub проверяет его в TMDB и хранит в
закрытом файле рядом с базой. Сохранённый ключ не передаётся в браузер.

Для автоматизированных установок можно задать токен в приватном окружении
процесса. Настройка, сохранённая из веб-интерфейса, имеет приоритет над
переменной. Для русских описаний используйте `FILEHUB_TMDB_LANGUAGE=ru-RU`.
Язык по умолчанию — `en-US`.

```ini
FILEHUB_TMDB_TOKEN=<API Read Access Token>
FILEHUB_TMDB_LANGUAGE=ru-RU
```

FileHub передаёт TMDB название и год произведения. Загрузка совпадений идёт
в фоне. Карточка в веб-интерфейсе содержит кнопку «Уточнить совпадение» для
администратора. Сохранённый выбор действует для всех клиентов этой медиатеки.
В «Продолжить просмотр» запасным вариантом для тёмного кадра служит постер.
Условия и требования к атрибуции описаны в [документации TMDB](https://developer.themoviedb.org/docs/faq).

## Разработка

В Android используется MapLibre Native 12.0.0, Kotlin 2.0.21 с Compose plugin,
AGP 8.6.1, Gradle 8.7, JDK17 и compileSdk35. targetSdk34 и minSdk26 сохранены.
Нужен сервер 1.40.2 для общего стиля карты; прежнее приложение совместимо с новым
сервером. Веб-карта загружается отдельным JS-модулем при открытии «Мест».
