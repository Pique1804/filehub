# Проверка Filehub 1.40.1 — 2026-11-15

Позднее в этот же день отдельно проверены перенос базы и откат, затем с разрешения
владельца обновлена существующая установка 1.40. Результаты: [обновление и откат](upgrading.md).

Готовые файлы собраны на Windows и проверены в тестовом Debian 12 в LXC. При установке
пользователю не нужны Go, Node.js, Gradle или Android SDK. Репозиторий остаётся
приватным. GitHub Actions не использовался для сборки: единственный разрешённый
запуск был остановлен GitHub до начала заданий из-за ограничений аккаунта.
Платные функции и изменение лимитов расходов не включались.

## Настоящая установка и браузер

Новая именованная установка с собственными файлами, службами и портом прошла
создание аккаунта, проверку приватного кода настройки, повтор пароля, смену
режима хранилища без перезагрузки страницы, выбор фото-папки и завершение мастера.
Проверены фактическая загрузка JPEG, точные байты скачанного оригинала,
миниатюра, фотолента, страница подключения и скачивание именно нового APK.
Настоящий PDF отображён встроенным просмотрщиком Chrome внутри Filehub;
MP4 декодируется в видеопредпросмотре, Range возвращает точные запрошенные байты.
Именованные установки используют отдельную копию кода мастера и не заменяют
код действующей стандартной установки.

Ранее подтверждённая проверка монтирования ext4-образа, bind в LXC и восстановления
UUID после перезапуска относится к host-storage/установщику. Физические диски
владельца при этих проверках не форматировались и не использовались как фикстуры.
