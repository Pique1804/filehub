# Filehub: сервер и первоначальная настройка

`main` содержит Go/Svelte 1.40 и проверенный установщик вокруг опубликованных
сервера и Android APK 1.40. Нативный мастер Go и Android 1.41 остаются отдельной
незавершённой разработкой в `feature/first-run-storage`; готовый пакет их не выдаёт
за выпущенные бинарники.

Установка готового архива на Linux x86-64 с systemd:

```sh
sudo ./install.sh
```

Пакеты Debian/Ubuntu устанавливаются автоматически, адрес берётся из сети
этой машины. Для Proxmox выполняется `sudo ./install.sh --proxmox CTID --restart`
на хосте. Подробности: [distribution/prebuilt](distribution/prebuilt/README.md).
Go/npm/Gradle для этой установки не нужны.

Мастер создаёт администратора, затем предлагает обычную папку сервера либо
подключение готового диска. Можно выбрать несколько именованных источников
и независимо указать фото-папки внутри них. Это общие оригиналы для файлов
и фотоленты. После установки `/storage` добавляет источники и фото-папки,
а `/connect` показывает адрес, APK и назначение автозагрузки именно этого сервера.

Проверены настоящий Go/Nginx, обычная загрузка PNG на смонтированный ext4,
фотолента, миниатюра, настройки, повторное монтирование UUID и перезагрузка
LXC. Приёмка использует новый файл-образ, а не форматирование личных дисков.
Это не испытание всех USB-контроллеров и файловых систем.

Хостовый сервис и Proxmox-адаптер: [host-storage](host-storage/README.md).
Модель данных: [storage.md](../docs/storage.md).
Память и ограничения проверок: [resources.md](../docs/resources.md).
Разработка из исходников описана в [BUILD.md](BUILD.md).
