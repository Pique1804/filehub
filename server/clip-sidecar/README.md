# filehub CLIP sidecar — «поиск по смыслу» для фото

filehub-сервер лёгкий и без ML. Вся тяжёлая работа (CLIP на GPU) — здесь, на твоём
NVIDIA-ПК. Сервер только хранит векторы и делает по ним косинусный поиск (быстро, без GPU).

## Что делает
1. **Индексация (в фоне):** тянет у filehub список ещё не обработанных фото
   (`/api/embed/todo`), качает миниатюры, гоняет через CLIP на GPU, отдаёт векторы
   обратно (`/api/embed/push`). Возобновляемо — можно прервать и запустить снова.
2. **Текст-эндпоинт:** держит `/embed_text?q=...`, чтобы сервер мог превратить
   поисковый запрос в вектор (это дёшево, работает даже на CPU).

## Включение в FileHub

В новых установках визуальный поиск выключен. Если локальный обработчик уже
задан в `FILEHUB_CLIP_SIDECAR`, при первом обновлении сохраняется прежнее
поведение. При подготовке нового обработчика вместе с обновлением используйте
`FILEHUB_CLIP_DEFAULT_ENABLED=0` для явного включения через настройки. Администратор может менять состояние в **Настройки → Сервер →
Поиск по содержимому фото**. Здесь виден прогресс по доступным для индексации
фотографиям. При отключении FileHub отменяет очередь и запросы к модели,
оставляя сохранённый индекс на месте.

Параметр `FILEHUB_CLIP_SIDECAR` принимает адрес модели по HTTP или HTTPS на
loopback либо частном IP. Для модели на другой машине используйте доверенную
локальную сеть и разрешите доступ только серверу FileHub. В обработчик уходят
поисковая фраза и миниатюра выбранного для индексации фото.

## Вариант для CPU с ONNX

Используйте `model_q4.onnx`, `tokenizer.json` и `preprocessor_config.json`
из зафиксированной версии модели в [исследовании #50](../../docs/semantic-search-evaluation.md).
В отдельном виртуальном окружении нужны Python 3.11, onnxruntime, numpy,
tokenizers и Pillow. Модель загружается при первом запросе. Обработчик
выполняет одну операцию за раз и использует один поток ONNX Runtime.

```sh
python3 onnx_server.py --model-dir /path/to/clip --port 8901
```

CLIP этой версии обучен на английских описаниях. Для запросов по-русски
установите `ctranslate2==4.6.3`, `sentencepiece==0.2.1` и распакуйте пакет
[Argos Translate Russian → English 1.9](https://argos-net.com/v1/translate-ru_en-1_9.argosmodel).
Передайте путь к распакованному каталогу `--ru-en-dir /path/to/translate-ru_en-1_9`.
Переводчик загружается при первом русском запросе и использует один поток
CPU. Запросы обрабатываются локально. Готовые векторы фотографий подходят для
поиска после обновления.

Для запуска на той же машине задайте
`FILEHUB_CLIP_SIDECAR=http://127.0.0.1:8901`. Если обработчик запускается на
другой машине, задайте её локальный адрес через `--bind` и IP сервера FileHub
через `--client`.

## Установка (Windows/Linux с NVIDIA)
```
python -m venv venv
venv\Scripts\activate            # Linux: source venv/bin/activate
pip install torch --index-url https://download.pytorch.org/whl/cu121
pip install -r requirements.txt
```

## Запуск (на GPU-ПК)
```
set FILEHUB_URL=http://filehub.example.test:8080
set FILEHUB_USER=admin
set FILEHUB_PASS=пароль
set SIDECAR_BIND=192.0.2.20
python sidecar.py
```

Подставьте адрес своего сервера FileHub и локальный IP компьютера с моделью.
Используйте команды `set` в CMD или `export` в Linux. При работе на той же
машине можно оставить `SIDECAR_BIND` равным `127.0.0.1`. Для удалённого
подключения разрешите доступ к порту только серверу FileHub в брандмауэре.
При первом запуске обработчик скачает модель и начнёт индексацию.

Если вы используете CPU-обработчик `text_only.py` на отдельной машине,
задайте её IP через `FILEHUB_CLIP_TEXT_BIND` и IP сервера через
`FILEHUB_CLIENT_IP`. По умолчанию оба значения — `127.0.0.1`.

## Включить на сервере filehub
Если FileHub установлен нативным мастером, выполните
`sudo systemctl edit filehub-onboarding.service` на сервере. Если при установке
выбрали другое имя службы, укажите его вместо `filehub-onboarding.service`.
Добавьте параметры окружения в секцию `[Service]`.

```ini
[Service]
Environment="FILEHUB_CLIP_SIDECAR=http://127.0.0.1:8901"
```

Перезапустите эту службу. Для модели на другом компьютере подставьте его
локальный адрес и порт. В установке с собственной службой можно задать
переменную через уже подключённый файл окружения.

```
FILEHUB_CLIP_SIDECAR=http://127.0.0.1:8901
```
Включите поиск в настройках сервера. Для внешнего индексатора обновите
`sidecar.py`, чтобы он передавал ревизию файла из `/api/embed/todo`.
Индексатору нужна учётная запись администратора FileHub.

## Проверка
- Прогресс индексации: `GET /api/embed/status` → `{embedded, total}`.
- Поиск: `POST /api/search/semantic?q=кот` → топ фото по близости.

Модель по умолчанию `ViT-B-32 / laion2b_s34b_b79k` (512-мерные векторы). Если
поменяешь — поменяй и `embModel` в `semantic.go` (это просто метка) и переиндексируй.
